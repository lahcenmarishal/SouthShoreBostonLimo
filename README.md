# South Shore Boston Limo

Site vitrine professionnel pour **South Shore Boston Limo**, spécialisé dans les services de transport privé et de limousine dans la région de Boston.

Site en ligne : southshorebostonlimo.com

## Le problème

Les clients recherchant un service de limousine ou de transport privé ont besoin d'une solution fiable, professionnelle et facile à réserver.

## La solution

South Shore Boston Limo présente ses services à travers une plateforme moderne permettant aux clients de découvrir les prestations et de contacter facilement l'entreprise.

1. Présentation de l'entreprise et de ses services.
2. Présentation des différentes solutions de transport.
3. Contact rapide pour demander un service ou une réservation.

## Fonctionnalités

- Présentation des services de limousine
- Transport privé
- Présentation de l'entreprise
- Formulaire de contact
- Demande de réservation
- Intégration téléphone et email
- Design responsive
- Interface moderne et professionnelle

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS

## Installation

git clone https://github.com/lahcenmarishal/SouthShoreBostonLimo.git  
cd SouthShoreBostonLimo  
npm install  
npm run dev
